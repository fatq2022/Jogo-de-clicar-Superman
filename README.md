# 🚀 Jogo de Clicar: Superman vs Palhaço

Este é um jogo simples de sobrevivência desenvolvido em **Python** utilizando a biblioteca **Pygame Zero**. O objetivo é controlar o Superman e evitar que o palhaço o alcance enquanto você o movimenta pela tela.

## 🕹️ Como Jogar
- Use o **Mouse** para clicar onde deseja que o Superman vá.
- Se o palhaço encostar em você, o jogo volta para o menu inicial.
- O jogo possui efeitos sonoros integrados para cada clique.

## 🛠️ Tecnologias Utilizadas
- Python 3
- Pygame Zero (pgzero)

## 📁 Estrutura do Projeto
- `main.py`: Código principal do jogo.
- `/images`: Contém os sprites do herói e do inimigo.
- `/sounds`: Contém os efeitos sonoros do jogo.
